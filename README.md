# Flight Reservation Automation (UiPath)

## Overview

This UiPath automation simulates a flight reservation process.

The bot:

* Requests destination from the user
* Requests departure date
* Requests return date
* Stores reservation details in an array
* Creates a reservation confirmation text file
* Saves the reservation details automatically

## Technologies Used

* UiPath Studio
* Input Dialog
* Arrays (String[])
* Assign Activities
* Write Text File

## Workflow

1. User enters destination.
2. User enters departure date.
3. User enters return date.
4. Data is stored in an array.
5. Confirmation text is generated.
6. ReservationConfirmation.txt is created.

## Example Output

Flight Reservation Confirmation

Destination: Dubai

Departure Date: 15/06/2026

Return Date: 22/06/2026

Your reservation has been successfully recorded.
